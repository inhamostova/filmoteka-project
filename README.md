# 🎬 Filmoteka

Filmoteka is a responsive web application for browsing, searching, and managing
a personal movie library using **The Movie Database (TMDB) API**.

The project was originally developed as a **team project** during the **GoIT
Fullstack Developer Course**.

After completing the course, I continued working on the application
independently, focusing on:

- code refactoring;
- improving project architecture;
- fixing bugs;
- enhancing UI/UX;
- adding new features and polishing the overall user experience.

## ✨ Features

- Browse trending movies
- Search movies by title
- View detailed movie information in a modal window
- Add movies to **Watched** and **Queue**
- Store personal movie lists in **Local Storage**
- Pagination for movie lists
- Responsive design for mobile, tablet, and desktop devices

## 🛠 Technologies

- HTML5
- SCSS
- JavaScript (ES6 Modules)
- Axios
- TMDB API
- TUI Pagination
- Parcel

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/InhaMostova/filmoteka-project.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm start
```

Build the project:

```bash
npm run build
```
